# BGTS BilgeAdam Staj — Hafta 1 Teslim Paketi

Bu klasör, ilk hafta boyunca yapılan AI Engineering çalışmalarının mentorla paylaşılabilecek düzenli kopyasını içerir. Kaynak dosyalar `docs/` altında yaşamaya devam eder; burası teslim ve inceleme için hazırlanmış pakettir.

## Okuma sırası

1. `01_Raporlar/11_Teslim_Manifesti.md`: Beklenen her teslim çıktısının hangi dosyada bulunduğunu gösterir.
2. `01_Raporlar/01`–`10`: Model mantığı, embedding, RAG, yerel model deneyi ve kurumsal senaryo raporları.
3. `02_Not_Defteri`: Öğrenilen kavramların kısa tanımı, kullanım yeri ve örneklerini içeren kişisel not defteri. HTML dosyası düzenlenebilir kaynak; PDF yazdırılabilir sürümdür.
4. `03_Kanitlar`: Benchmark, test seti ve kalibrasyon sonuçlarının ham JSON kanıtları.
5. `04_Canli_Demo`: Sunum sırasında çalıştırılabilecek, adım adım Qdrant → retrieval → reranker → no-answer akışını gösteren tekrar üretilebilir demo.

## Dürüstlük sınırı

`09_Kurumsal_Senaryo_Klinik_Akis.md` içindeki Klinik Akış, özel diş klinikleri için seçilmiş gelecek ürün fikri / daraltılmış MVP senaryosudur. Gerçek hasta pilotu veya canlı üretim kullanımı olarak sunulmaz. Rapor, sonraki haftalarda geliştirilecek sistemi ve güvenlik sınırlarını tanımlar.

## Düzenleme notu

Raporlar Markdown biçimindedir ve düzenlenebilir. Not defterinde değişiklik yapmak için HTML dosyasını düzenleyip PDF'i yeniden üretmek gerekir.
